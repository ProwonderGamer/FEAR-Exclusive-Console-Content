    How to play

    Getting started

    Avoid using older save files created before installing or updating this mod, as they may cause missing content, unexpected behavior, or bugs.

    Bonus missions & Instant Action

    • Bonus missions: Main Menu → Bonus mission
    • Instant Action: Main Menu → Instant action

    Xbox 360 HUD

    On by default. Switch between the Xbox 360 and PC layouts in Options → Game → HUD layout.

    Console weapons

    Press T, type the command, press Enter:

    • Watson: gimmegun zSFODD_AutoShotgun
    • SM15: gimmegun zSFODD_Machine Pistol

    guns gives every weapon.

    Weapon commands

    PLAYSTATION 3 WEAPON

    1. Start or load a game.
    2. Press T to open the console.
    3. Type the command exactly as shown, spaces included, then press Enter.

    Get EchoPatch

    REQUIRED
    EchoPatch by Wemino

    A free fix for the PC version of F.E.A.R. This mod needs it.

    1. Open the EchoPatch page and download the latest release.
    2. Copy dinput8.dll and EchoPatch.ini into your game folder, next to FEAR.exe. If Windows asks to replace dinput8.dll, choose Replace.
    3. Come back here and press Verify.
    github.com/Wemino/EchoPatch
